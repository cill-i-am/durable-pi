# App-event runner lifetime

**Release status — 25 October 2026:** the refactor is [merged, deployed and verified](xstate-effect-release.md). The checkpoints below retain their original source and test scope; pre-merge delivery status is historical.

The Apps event ledger, discovery lease and delivery/render machines already own durable business state. This slice replaces the remaining local dispatch Map in `AppEventRunner` with `apps/runner.machine.ts`, hosted through the official Effect integration in the runner's scope. It preserves the existing job IDs, payload versions, lease deadlines, native callback identity, spent markers and Lifecycle's three attempts. No data migration or new retry budget is added.

The machine distinguishes a running callback, its failed attempt and exhausted cleanup. Only the exact callback may resume a failed attempt. A duplicate of the same callback is deferred while its native pump remains held; an overlapping error callback cannot spend that lease. Both cases are reproduced failures against the preceding adapter. Native jobs remain SDK-owned.

Scheduling calls have an acknowledged machine-owned slot and waiting queue. This preserves the read/decision/write order when asynchronous actor messages replace the old synchronous Map checks. A callback delivered during a queue update is deferred. Doorbells during retained dispatch only rearm; they cannot renew the attempt budget. Orphan leases remain fenced until their original deadlines and terminal persistence precedes new admission.

Close refuses new work, releases queued callers and joins accepted native promises before closing the actor scope. A caller refused a late admission lease is an admission result; it does not become a spurious cleanup failure. Native failures, defects, interruption and annotations survive at both callback and disposal boundaries. PersonalAgent joins App-event shutdown concurrently with provider/credential/Coordination shutdown before closing runtime and SQL resources. The native held-callback test reads actual configuration through that runtime after release; removing the host join fails its ordering assertion.

The host retains only native Promise handles and one idempotent disposal Promise. These are resource handles, not independently writable callback permissions. Lazy scoped actor creation preserves the caller's native context. Durable discovery uses its existing synchronous decision machine and native storage.

Local verification: 19 App lifecycle cases cover existing retained discovery/exhaustion, cold compatibility, stale/spent callbacks and orphan recovery, plus same-callback overlap, premature failure, held/queued shutdown, full compound failures with and without a defect, and malformed-event rejection. The native Apps restart test passes without poking the object through its discovery deadline, retaining exact receipts and bounded retries. The full PersonalAgent native suite verifies the joined host lifetime. Final local static checks, all 3,711 tests in 329 files, website/route verification, seven Worker bundles and the full PersonalAgent native suite pass. [Raw publication evidence](evidence/xstate-effect/app-runner-2026-10-24/README.md) includes negative controls and source hashes; [draft PR #224](https://github.com/cill-i-am/durable-pi/pull/224) at unsigned `6801492` passed all required [hosted CI](https://github.com/cill-i-am/durable-pi/actions/runs/40124041665), with deployment skipped. Browser and container behavior is unchanged; the composed parent has the corresponding full local gates, and final PR CI runs the required repository checks.

Conversation, Communication, Workspace, Routine, Summary and Backup runner gates remain open in the inventory. This slice does not complete the repository-wide goal or authorize merge/deployment.
