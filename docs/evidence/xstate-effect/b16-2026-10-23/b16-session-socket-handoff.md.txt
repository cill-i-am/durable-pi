## Invariants / parity

1. Initial authority lease is 15 seconds. Successful current authorization can renew only before its live deadline; timer lag cannot revive expired authority.
2. Both directions check the live clock at machine admission. Closure is terminal and all later events are fenced. Queued close precedes later queued frames.
3. One read-only auth check is in flight. Checks retain the original 5-second clock cadence; a slow check skips occupied ticks without issuing another check.
4. UTF-8 and ArrayBuffer frames at 256 KiB pass; anything larger closes both peers with 1009. Revocation/expiry closes with 1008; auth failure closes with 1011.
5. Scope cleanup attempts every registered listener removal and both endpoint closes, including partial add/accept failures. Full native Cause reasons survive, including repeated defects, Fail and Interrupt reasons.
6. Socket closure and auth settlement are separate observations. Both sockets/listeners/timers close while held read-only auth is outstanding; the lifetime settlement remains pending until that native check actually settles. Late success cannot reopen; late compound failure remains visible in the joined outcome.
7. The proxy host positively retains successful socket lifetimes. Failed retention/request cleanup joins actual settlement before returning its combined failure.

## Concrete defect characterized before repair

The old four-test suite passed. An additional test starts held auth at 5 seconds, advances the live wall clock to 15,001 ms without firing the interval callback, resolves auth true, and sends input. Old code renews the expired deadline and forwards `expired input`. The new machine denies it. Baseline and pre-fix red logs are retained below.

## Observable compatibility change

`close()` remains a synchronous callable signal with the same optional close code/reason shape. Official actor mailbox processing is asynchronous, so cleanup failure is now reported through `close.settled` / `session.settled` and the supplied `failed` callback, not thrown synchronously from the signal. Existing production caller is updated to retain/join settlement. Tests explicitly await processing/settlement. Partial construction failures still throw their complete synchronous acquisition/cleanup Cause.
