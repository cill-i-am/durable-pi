# Transport host lifetimes

**Release status — 25 October 2026:** the refactor is [merged, deployed and verified](xstate-effect-release.md). The checkpoints below retain their original source and test scope; pre-merge delivery status is historical.

B16 moves application-owned transport admission, observation, cancellation and joined release into official `@xstate/effect` machines. Effect retains native resources and their complete settlement. SSE, the model SDK protocol, Access policy, Pi execution and the existing durable ledgers keep their owners.

## Ownership

| Owner | Machine and progression | Resource capability |
| --- | --- | --- |
| Authenticated session socket | `src/auth/session-socket.machine.ts`: open/idle, checking, closing, closed. A successful check can renew only a live lease; every frame checks its current deadline. | `src/auth/adapters/session-socket.ts` owns both socket endpoints, registered listeners, timers and the actual authorization promise. The proxy retains and joins its settlement. |
| Upstream diagnostic request | `src/agent/upstream.machine.ts`: admitting, ready, streaming, closing, closed. Admission acknowledgement and response handoff are distinct. | `src/agent/adapters/upstream.ts` joins local reader cancellation and remote release, including cancellation during admission. |
| Upstream observation lease | `src/agent/upstream.machine.ts`: idle, leased/available, leased/claimed, releasing, closed. Claim transfers the sink once; expiry cannot cancel inference. | PersonalAgent supplies the scoped observer and retains settlement. The map-free machine owns lease availability. |
| Relay and provider response | `src/inference/upstream.machine.ts` owns observer expiry and provider acquisition, body pumping and joined close. | `src/inference/adapters/upstream.ts` and `upstream-worker.ts` implement native streams/RPC and bounded observation buffering. |
| Model request and model host | `src/inference/model-stream.machine.ts` owns per-request acquisition, reading, publication and close; host admission and shutdown are independent. Synchronous request and consumer decisions also use the official machine definition. | `src/inference/adapters/streams-pi.ts` owns provider callbacks, readers, bounded queues and actual settlement. Pi and the provider SDK retain their execution/protocol internals. |
| Native Access callback | `src/access/callback.machine.ts` owns exact-input sharing until joined settlement, then authority resolution and consequential Access dispatch. | `src/access/adapters/pi.ts` indexes the exact live promise and invokes the existing Access gate. It freezes accepted argument bytes before yielding. |
| Native Terminal host | `src/terminal/native-host.machine.ts` owns exact import reservation, waiting for admitted video cleanup, import and settlement; it reuses the existing video reservation machine. | `src/terminal/native-host.ts` retains actual video/import promises; the native Worker supplies the unchanged migration and capacity capabilities. |
| Terminal host | `src/terminal/host.machine.ts` owns video/snapshot admission, irreversible host freeze, exact-owner release and the finite migration drain. | `src/terminal/host.ts` owns native promises and scoped work; `src/terminal/worker.ts` supplies existing Terminal and migration capabilities. |

The synchronous callback, request, consumer and Terminal reservation decisions use official `initialTransition`/`transition` over `setupEffect` definitions. Their live maps index resources; they do not decide a parallel lifecycle. Asynchronous stages start with `createEffectActor` inside an explicitly owned Effect scope.

The B16 inventory originally omitted `streams-pi.ts` and `src/terminal/adapters/native-worker.ts`. Caller discovery found application provider admission, request cancellation, capacity rejection and shutdown in the former, and native video/import admission in the latter. Both are included in this migration. `models-pi.ts` continues to perform consequential authority checks. Sign-in and credential rotation remain B15. MCP connection ownership remains B17. The credential, model, observation, communication and runtime shutdown calls in PersonalAgent are resource composition; the individual machines own admission and drain. Delegation's existing shutdown composition consumes the same model-host service and requires no competing host controller.

Terminal's durable command/claimant cleanup, capacity protocol and migration ledger are unchanged. Native import admission freezes new video work, waits for already-admitted video cleanup, and compares immutable owner, name, key, digest and size against active work and the existing persisted receipt. Exact active retries share the same joined promise; conflicting fields fail before import. After settlement, video admission still requires the existing ledger to report `original` or `done`. Native-host calls use the actual runtime `runPromiseExit` capability so interruption cannot squash a Cause before another local operation joins it.

The legacy Terminal host's former `videoBusy`, `snapshotting` and handwritten drain loop were host-owned progression and have been removed. `LEGACY_FROZEN` and the durable migration status remain inputs to admission, not writable copies of the host machine.

## Invariants and budgets

- Socket authority starts with a 15-second lease and the existing five-second check cadence. Only one check may be outstanding. A delayed successful check cannot revive expired authority. Each UTF-8 or binary frame retains the 256 KiB limit. Closing stops forwarding and closes endpoints/listeners while still joining an outstanding read-only authorization promise.
- Diagnostic and marker observation retain the existing one-minute bound. A slow or expired observer cannot keep an inference response alive, cancel it, or consume its body. The provider stream continues independently. SSE framing and response headers remain unchanged.
- Model streams retain their 16 active-provider limit, ten-minute request lifetime, 128 queued-event bound and 16 MiB provider-response bound. Capacity rejection still has a completion callback, so shutdown must join it even though it never acquired a provider slot. Starting the same request object again cannot dispatch another provider request.
- Access callback sharing requires the same call ID, tool and serialized argument content. Immutable accepted bytes feed both the operation ledger and native invocation. Aborting a callback revokes future work but does not free its slot before native completion and cleanup join. The existing Access gate remains the final authority owner. Its execute stage rechecks current run authority after the claim-to-execution actor handoff, immediately before native work. Revocation retains the already-claimed row without a fabricated result.
- Terminal allows one video operation while writable. A snapshot freezes admission before any await, shares only its exact active name, and stays frozen after completion or failure. Its drain retains the existing 60-second deadline and 250 ms wait cadence. Exact owner tokens release occupancy only after actual settlement. A failed snapshot requires an explicit same-name retry.

These are local resource lifetimes, not durable business attempts. B16 adds no resource snapshots, SQL fields, migrations, execution journal, retry scheduler or new persistent identity. Cold hosts reconstruct live resources through their existing owners; they do not restore an unfinished Effect as permission to repeat an external action. Package pins remain those in the canonical standard. There is no stored B16 schema/workflow conversion to perform.

## Intentional defect corrections

The original focused suites were run before adding characterization tests. The following traces then failed against the old implementation:

| Trace | Old outcome | Required outcome |
| --- | --- | --- |
| Start socket authorization at five seconds, move the live clock past the lease without firing its timer, then resolve authorization successfully. | The success renewed expired authority and forwarded input. | Close with authentication expiry; late success never reopens. |
| Mutate a native tool callback's argument object immediately after invocation but before authority resolves. | The ledger/sharing identity described the original bytes while native dispatch received the mutation. | Ledger identity and native dispatch both use the immutable admitted input. |
| Call the real Terminal worker `/video` handler while migration is frozen. | Video extraction still starts. | Return 503 before extraction. |
| Cancel an upstream response while remote release is needed to unblock local cancellation. | Serial cleanup deadlocks. | Start both releases and join both outcomes. |
| Cancel while observation admission itself waits for local reader cancellation. | Waiting for admission before cancelling prevents admission from settling. | Start local cancellation immediately; still await that original admission before remote release. |
| Start a model request twice, or close the host while a capacity-refused request's completion callback is held. | The request could dispatch twice; shutdown could finish before the refused callback. | One request reservation, and shutdown joins every accepted completion obligation. |
| Native cleanup returns a compound Effect Cause. | Some Promise boundaries nested it inside a single defect. | Preserve original failure, defect and interruption reasons through joined cleanup. |
| Terminal drain fails through the actual ManagedRuntime Promise boundary. | Re-entering the rejected Promise lost the original cleanup defect and annotations. | Carry Exit through the internal boundary before re-entering Effect; retain the complete Cause. |
| Run authority is revoked after the Access ledger claim but before the execute actor starts. | Native dispatch still occurred. | Recheck authority in execute immediately before work; no native dispatch or result. |
| A native import is held and a retry changes the storage key or size while keeping owner and digest. | The retry inherited the original import result. | Compare all five receipt fields and reject the conflicting retry. |
| A provider reader fails with a compound Effect Cause before the SDK normalizes its error. | The original cleanup defect disappeared into an ordinary model error. | Retain the original Cause at the read boundary; ordinary network errors keep their existing behavior. |

`bindSessionSocket.close()` remains a synchronous close signal. Official actor event processing is asynchronous; cleanup errors are now observed through `close.settled` / `session.settled` and the failure callback rather than thrown synchronously by the signal. The production proxy retains the lifetime and joins it during failed handoff cleanup. Partial synchronous construction failure still reports its acquisition and cleanup Cause.

Native workerd can reject a pending stream read with its raw cancellation acknowledgement after an initiated cancellation. The upstream boundary recognizes that acknowledgement only when it owns cancellation; an arbitrary failure or full compound Effect Cause remains a failure.

## Evidence and limits

Focused deterministic tests cover immutable admission, stale/late completion, exact sharing, held native cleanup, partial acquisition, compound Causes, delayed authorization, bounded queues, capacity rejection, observer expiry and Terminal's finite drain. The worker `/video` regression invokes the actual production handler with synthetic host capabilities; it is not a real-container certification.

The existing `scripts/test-upstream-runtime.mjs` runs actual workerd/RPC and synthetic providers. It checks response streaming and cancellation, observer disconnection, and inference continuing beyond the one-minute observation lease. No live model, authenticated account or external provider is used.

Failure-sensitive controls change only test bundles: removing the socket live-deadline check, replacing immutable callback arguments with the caller's mutable object, bypassing frozen Terminal admission, restoring serial upstream cleanup, removing the final Access authority check, and removing the internal Terminal Exit bridge must each fail the corresponding behavioral assertion. Production source hashes are checked around these controls.

A fresh reviewer reproduced and rechecked the Terminal nested-Cause and Access claim-to-dispatch failures against the actual runtime/ledger boundaries. The repaired Access/Terminal slice passed 33 focused tests across five files plus scoped type, lint and format checks. Socket and proxy tests passed 36 cases; upstream tests passed 24 cases and the native relay suite. Inference passed 60 focused tests, including the unchanged independent reader-Cause probe after its narrow fix. The composed B16 focused command passed 176 tests across 16 files; scoped lint and formatting passed for all 32 changed files. Native-host tests include 23 cases and a source-preserving exact-identity mutation control. A fresh reviewer also verified all five immutable receipt fields, held cleanup, explicit retry and late annotated Causes through the actual ManagedRuntime `runPromiseExit` boundary, with no remaining finding. Final source manifests and raw local proof logs are listed in the lane handoff. Repository-wide checks belong to the final composed tree. These local resource tests make no exactly-once provider-delivery, production-deployment, live credential or real-container claim.

## Composed publication candidate

The implementation is composed above published credential commit `d82998d`, retaining the Memory summary/backup shutdown owners alongside model, credential and upstream drains. Full static checks, 3,313 tests in 291 files, website/routing and all Worker builds pass. The final full unit run used two local workers: an unchanged memory materialization test exceeded its existing five-second deadline during parallel native work, passed in isolation, then passed with the complete suite. Neither assertions nor timeout were changed.

The unchanged actual Communication/PersonalAgent suite and independent upstream suite pass. Integration first exposed a real shutdown regression: the provider body was released correctly but owner shutdown returned an aborted SDK message instead of interruption. The request machine now distinguishes owner `INTERRUPT` from ordinary caller `STOP`, retains complete cleanup failures and joins the original operation. Actual SDK positive/negative cases, an independent review and the unchanged native assertion verify the correction. The HTTP route fixture now supplies its actual scoped upstream owner; its assertions are unchanged. Final source hashes, raw integration failures, repairs and successful gates are linked by [publication manifest](evidence/xstate-effect/b16-publication-manifest.json). Exact-commit hosted CI remains required; no merge, deployment or live-provider effects are claimed.
